# Excel 输出契约

正式工作簿固定4个 Sheet，保持管理层可读、素材级可追溯，并用关键帧佐证画面判断。

## Sheet 1：素材总览

每条视频一行：素材编号、原始文件名、时长（秒）、画幅、产品/品类、核心钩子、成交模型、模型状态、一句话成交链、画面证据编号、跑量逻辑、最大优点、主要不足、合规风险、模型置信度、建议素材池角色、优先级。

## Sheet 2：逐段拆解

每个语义段一行：素材编号、原始文件名、起始时间、结束时间、画面/口播/字幕、画面证据编号、内容功能、停留作用、信任作用、成交作用、可复刻点、风险/缺口。

## Sheet 3：复刻策略

每条素材一行；末尾允许增加“全组横向策略”行：素材编号、成交模型、目标用户购买前状态、购买触发、信任/价值建立、主要异议与处理、交易加速器、现在购买理由、必须保留模块、可替换表现元素、失效条件、团队拍摄清单、可复用脚本骨架、下一轮单变量测试、成功指标、事实核验项。

## Sheet 4：画面证据

每张关键帧一行：证据编号、素材编号、原始文件名、时间戳（秒）、证据角色、支持的分析结论、证据边界、关键画面。

- 每条视频通常3–5张，按时间顺序排列。
- 图片嵌入工作簿，不使用仅本机可见的外链。
- 图片保持原始比例，缩略图建议不超过160×100像素。
- 图片缺失时仍保留证据记录，并明确标“图片文件缺失”，不能静默跳过。

## 格式

- 深色标题带、蓝色表头、浅灰说明区；冻结表头和关键标识列。
- 长文本自动换行、顶部对齐；优先拓宽列，避免不可控超高行。
- 秒数为数值格式 `0.0`；率指标如扩展则用 `0.0%`；金额如扩展则用 `#,##0.00`。
- “高风险/待核实”使用浅红条件格式，“模型级验证”使用浅绿，“推定”使用浅黄。
- 画面证据Sheet每行高度约90–110，图片不得覆盖相邻记录或文字。
- 不创建装饰性图表。只有投放数据足够且能形成有意义比较时才增加图表。
- Sheet标题、报告时间范围、数据来源、缺失资料和口径必须可见。

```json
{
  "reportTitle": "品牌视频素材成交模型拆解",
  "sourcePath": "/path/to/videos",
  "scopeNote": "未提供投放后台数据，跑量逻辑为结构判断",
  "outputPath": "deliverables/report.xlsx",
  "overview": [],
  "segments": [],
  "replication": [],
  "evidence": []
}
```

对象字段使用构建脚本中的英文 key。未知值使用 `null` 或空字符串；数值未知不能填0。
