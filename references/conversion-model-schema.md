# 成交模型 Schema

## 定义

成交模型是一条素材推动特定用户完成购买决策的最小因果解释：

`目标用户购买前状态 → 购买触发 → 信任/价值建立 → 主要异议处理 → 交易加速 → 现在下单理由`

它不是题材、卖点清单、内容公式或单个心理学名词。

## 标准输出

```text
成交模型名称：
模型状态：推定 / 素材级有效 / 模型级验证
目标用户购买前状态：
成交因果链：A → B → C → D → E
购买触发：
信任/价值建立：
主要异议与处理：
交易加速器：
现在购买的核心理由：
不可缺少的模块：
可替换的表现元素：
失效条件：
证据与数据边界：
模型置信度：高 / 中 / 低
```

## 判断步骤

1. 描述用户看见素材前的认知、需求和犹豫。
2. 引用前3秒脚本或画面，识别购买触发。
3. 区分“声称”与“证明”，识别价值和信任如何建立。
4. 找出最重要的1–2个异议，并判断内容是否处理。
5. 判断是否存在真实交易加速器；普通“快下单”不算。
6. 把因果链压缩为3–6个节点，再用“核心机制＋成交模型”命名。
7. 写明去掉什么会失效，以及人物、场景、话术哪些可以替换。
8. 根据数据判断模型状态，不用播放指标代替成交指标。

## 常见命名示例

下架稀缺、身份代入证言、源头直供低价、感官奇观尝鲜、问题自测解决方案、专家解释信任、老客背书价格机会。示例不是固定分类表，必须从真实因果链出发。

## 聚合规则

- 同题材、同人物、同内容公式不必然是同模型。
- 不同题材若购买触发、信任、异议处理和交易加速一致，可以归为同模型。
- 单条素材有效只能写“素材级有效”；至少两条独立脚本并有足量成交证据，才考虑“模型级验证”。
- 聚合后仍要保留具体素材和证据的追溯关系。

## Prompt核查问题

- 如果去掉优惠，这条内容还有购买理由吗？
- 如果换一个人物，因果链是否仍成立？
- 用户相信的是产品证据，还是只相信人物？
- 用户只是想继续看，还是已经获得购买理由？
- “现在买”的理由真实吗？
- 有什么数据能支持成交，而不只是支持停留？
